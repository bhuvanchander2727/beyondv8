# BEYOND — Founder Portrait Assets

Place authentic founder and co-founder photographs in this folder:

- `founder-01.jpg` (or `.png` / `.webp`): Primary Founder & Creative Director portrait (recommended aspect ratio: 3:4 or 4:5, minimum 800x1000px).
- `founder-02.jpg` (or `.png` / `.webp`): Co-Founder portrait.
- Additional portraits: `founder-03.jpg`, etc.

Update names, roles, biographies, quotes, and social links in:
`src/data/founders.json`

The BEYOND About page automatically renders any number of profiles dynamically from `src/data/founders.json`.
